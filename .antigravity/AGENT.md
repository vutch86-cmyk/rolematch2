# RoleMatch 2 - Agent Guidelines

## Commit & Branch Rules
- Luôn tuân theo chuẩn Conventional Commits (ví dụ: `feat:`, `fix:`, `refactor:`, `chore:`).
- Trước khi commit hoặc tạo PR, kiểm tra code sạch sẽ, không commit các file bí mật (`.env`, secrets, token).
- Luôn kiểm tra build/tests trước khi tạo commit hoàn tất tác vụ.
